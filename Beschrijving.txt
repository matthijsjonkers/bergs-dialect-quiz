Beschrijving: Bergs Dialect Quiz (Buzzerpaneel)

Wat het is
Een offline te gebruiken quiz-app voor je mobiel, gebouwd bovenop hetzelfde
rood/groen buzzerpaneel-idee als de C#-quiz. In plaats van een voorgelezen
vraag speelt de app een mp3-fragment af (spelling + betekenis van een Bergs
dialectwoord). Gebouwd als PWA (installable web-app) zodat hij ook bij een
kleine 4000 fragmenten nog soepel en volledig offline werkt.

Hoe het werkt
1. Start de quiz. Er speelt een willekeurig woord-fragment af.
2. Je hoeft niet te wachten tot het einde: zodra je het weet, tik je meteen
   rood (NIET GEKEND) of groen (GEKEND). Het fragment stopt dan direct.
3. 🔁 speelt het huidige fragment nog eens af, ook tijdens het afspelen.
4. Woorden die je als "niet gekend" markeert komen vaker terug in latere
   beurten, zodat je vooral herhaalt wat je nog niet kent.
5. Aan het eind van een beurt zie je hoeveel je gekend/niet gekend hebt.
   Je voortgang wordt lokaal bewaard (blijft staan na het sluiten van de app).

Techniek
- De mp3's blijven gewone losse bestanden in de map "mp3" (niet ingebakken
  in de HTML) — bij duizenden fragmenten zou dat één veel te groot bestand
  opleveren.
- Een service worker (sw.js) cachet bij de eerste keer opstarten alle
  fragmenten op de telefoon zelf. Daarna werkt de app zonder enige
  internetverbinding, ook als de pc/server niet meer aan staat.
- "words.json" is de woordenlijst; wordt gegenereerd door build.js.

Hosting
De app staat online via GitHub Pages (gratis static hosting), zodat hij
overal bereikbaar is — ongeacht of pc en telefoon op hetzelfde netwerk
zitten:
  Live url:  https://matthijsjonkers.github.io/bergs-dialect-quiz/
  Repo:      https://github.com/matthijsjonkers/bergs-dialect-quiz (publiek)
Publiek was nodig omdat GitHub Pages op een gratis account niet werkt met
een privé-repo. De quiz-site zelf was toch al voor iedereen met de link
bereikbaar; publiek betekent alleen dat ook de broncode op GitHub nu door
anderen bekeken kan worden.

Eenmalige installatie op je telefoon
1. Open in Chrome (Android) of Safari (iPhone):
     https://matthijsjonkers.github.io/bergs-dialect-quiz/
   De app laadt en begint direct met "Offline voorbereiden: .../..." —
   wacht tot dit "Klaar voor offline gebruik" toont.
2. Tik op "📲 Installeer app" (Android/Chrome), of op iPhone: Deel-knop →
   "Zet op beginscherm". Er verschijnt een icoon op je startscherm.
3. Vanaf nu werkt de app via dat icoon, volledig offline — ook zonder
   wifi/internet en zonder dat er een pc bij nodig is.

Nieuwe mp3's toevoegen
1. Zet de nieuwe mp3-bestanden in de map "mp3".
2. Draai: node build.js
   (dit herschrijft words.json en zet automatisch een nieuwe cache-versie
   in sw.js, zodat de telefoon weet dat hij opnieuw moet cachen)
3. Commit en push naar GitHub:
     git add -A
     git commit -m "Nieuwe woorden toegevoegd"
     git push
   GitHub Pages bouwt de site binnen ongeveer een minuut opnieuw.
4. Open de app nog een keer op je telefoon terwijl je internet hebt — de
   voortgangsbalk verschijnt weer en download alles (ook de ongewijzigde
   fragmenten) opnieuw naar de cache.

Lokaal testen zonder internet (optioneel)
"serve.js" (node serve.js) start een lokale webserver voor als je liever
zonder GitHub wil testen op je eigen wifi-netwerk. Let op: service workers
werken dan alleen als telefoon én pc op hetzelfde wifi zitten, en op
Android moet je bovendien handmatig chrome://flags/#unsafely-treat-insecure-origin-as-secure
inschakelen voor dat lokale adres (niet nodig bij de GitHub Pages-versie
hierboven, die heeft al echte https).

Beperkingen
- Bij het toevoegen van nieuwe mp3's wordt bij de volgende keer online
  openen de hele woordenlijst opnieuw naar de cache gedownload (niet
  alleen de nieuwe bestanden) — eenvoudig, en snel genoeg ook bij
  duizenden fragmenten.
- De repo is publiek: broncode en bestandenlijst zijn zichtbaar voor
  iedereen op GitHub.
